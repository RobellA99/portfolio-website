### Project 4: [ReccoBeats - Hackathon](#)

- **Description**: 24 hour hackathon to design and build any product and present an mvp. Built a music recommendation web app to help users find new music, based on 5 key criteria: from how much they want a song to make them dance to how much bass they prefer to listen to. Working with the ReccoBeats API a list of songs would be generated taking into account all the custom criteria and a brief description of each song and the artist that produced each song will be displayed.
- **Tech Stack**: JavaScript, HTML, CSS, ReccoBeats API, Git
- **Source Code**: Frontend - [https://github.com/RobellA99/ReccoBeats-Hackathon](#)
